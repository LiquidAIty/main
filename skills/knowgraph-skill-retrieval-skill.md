# Selecting Relevant Skills

@skill id=knowgraph-skill-retrieval
@type Skill
@status active
@related_to skillgraph

Historical filename retained during September 9, 2026 recovery from `2ddadeeb^`. Use to select
procedural context without loading every skill. No Neo4j skill index is required or implied.

Start with the actual task and recipient's job. Search the existing repository skill names and
descriptions, or use that Hermes profile's granted native skill discovery. Read the few relevant
procedures and follow specific references only when needed. Do not infer a universal numeric
skill limit from one successful task.

Skills explain how to work; project graphs supply what is known. Keep instructions out of
research facts and dynamic user chatter. The receiving saved Card owns its stable configuration.
No helper may rewrite the prompt or broaden tool grants based on keywords in the task.

Measure what was actually loaded and useful, not merely discovered. Distinguish a short skill
catalog from full skill contents; do not call listing overhead whole-skill injection. Reuse an
already read procedure within the task unless its source changed or an unresolved issue requires
another read. Check current source before relying on old symbol or command references.

Return only the needed procedure, source reference and relevant caveats. Do not hand the entire
skill library, every audit report, or an unbounded repository scan to the next agent. Missing
runtime skill discovery is a capability gap, not permission to recreate the deleted importer.
